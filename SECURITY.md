# Security Policy

## Supported versions

Until the first stable release, security fixes are provided for the latest published `0.x` version only.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use [GitHub private vulnerability reporting](https://github.com/bronekot/git-lineage/security/advisories/new).

Include:

- affected version and platform;
- a minimal reproduction;
- expected security impact;
- whether credentials or private repository data may have been exposed.

Remove live credentials from every report. You should receive an acknowledgement within seven days. A fix and disclosure timeline will be coordinated after the report is reproduced and assessed.
